- Found a real spec violation: `store/icon-512.png` was 24-bit RGB (color type 2, no alpha),
  but APKPure (and Google Play) require 32-bit PNG **with alpha**. Converted to RGBA
  (type 6, 512x512, 411 KB) and made it canonical at `store/icon-512.png`,
  `store/upload/icon-512.png`, `store/upload/icon-512-32bit.png`.
- Screenshots/feature graphic were already 24-bit RGB — correct for both stores.
- From the user's console screenshots: the square icon was also added as the first
  screenshot (wrong), content rating was set to 16+ (should be Everyone), and the
  App Name / Short Description fields (between Category and Add-an-icon) were never
  captured — most likely empty, which keeps SAVE disabled.
- Appended section ١٠ to `store/apkpure-listing.md`: 6 ranked causes + the fact that
  "Android developer verification: Not Verified" is a read-only status tied to Google's
  Android developer verification, not fixable inside APKPure.
