موسوعة تاريخ الإسلام — نسخة HTML أولية

المحتويات:
- index.html: الصفحة الرئيسية والفهرس والبحث عن الأقسام.
- sections/: صفحات HTML مستقلة لكل قسم رئيسي.
- css/style.css: تنسيق موحد للصفحات.

الاستخدام مع Cordova:
1. خذ نسخة احتياطية من مشروعك.
2. انسخ index.html ومجلدي sections وcss إلى مجلد www في مشروع Cordova.
3. لا تستبدل ملفات التطبيق الحالية قبل مراجعتها؛ ادمج الملفات مع مشروعك الحالي.
4. إذا كان مشروعك يحتوي على صفحة index.html خاصة به، افتحها أولًا وادمج تصميم الفهرس بدل استبدالها مباشرة.
5. اختبر الروابط على جهاز أندرويد بعد البناء.

هذه حزمة محتوى أولية مشتقة من المخطوط الموجود. لم تتم إضافة صور أو توثيق أكاديمي تفصيلي لكل فقرة.
