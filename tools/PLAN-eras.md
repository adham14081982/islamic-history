# خطة العصور — ١٢ عصرًا × ٥ أقسام × ٣ فصول

> كل عصر: ٥ أقسام، كل قسم ٣ فصول = **١٥ فصلًا**.
> الفصل الواحد لا يقل عن ٩٠٠٠ حرف (٧ فقرات + ٤ أقسام فرعية + ٥ بطاقات + جدول + اقتباس + خلاصة).
> ١٥ × ٩٠٠٠ = ١٣٥٠٠٠ حرف ≈ **٥٢ صفحة** لكل عصر. المجموع المستهدف ≈ ٦٢٠ صفحة.
> المجلد: `data/era/<اسم-الصفحة>/NN-<partId>.json` ثم `node tools/era.js all`.
