# دليل كتابة الأجزاء العميقة — موسوعة التاريخ الإسلامي

## المهمة
كتابة **ملف JSON واحد** يمثّل **جزءًا واحدًا** من حقبة تاريخية، ثم دمجّه في صفحة الحقبة.

عنوان الحقبة وفصولها محدّدة مسبقًا في `tools/PLAN-eras.md` — لا تغيّر العناوين ولا ترتبها، ولا تكرّر موضوعًا بين فصلين.

## الصيغة

```json
{
  "partId": "latin-slug",
  "partN": "اسم القسم بالعربية",
  "partIc": "🌙",
  "partLead": "مقدمة القسم: من ثلاث جمل إلى ست، ترسم حدود القسم وما يحمله.",
  "chapters": [
    {
      "id": "latin-chapter-slug",
      "n": "عنوان الفصل",
      "ic": "⚔️",
      "lead": "سؤال افتتاحي يشد القارئ",
      "p": [
        "فقرة أولى مكتملة، فيها أحداث وأسماء وتواريخ.",
        "فقرة ثانية تعمّق في نقطة مختلفة تمامًا."
      ],
      "h2": [
        { "t": "عنوان فرعي (٣ إلى ٦ كلمات)", "p": ["فقرة فرعية", "فقرة أخرى"] }
      ],
      "key": [ { "k": "مفتاح قصير", "v": "قيمة من جملة أو رقمين" } ],
      "tbl": {
        "head": ["عمود أول", "عمود ثانٍ", "عمود ثالٍ"],
        "rows": [["صف ١"], ["صف ٢"], ["صف ٣"]]
      },
      "quote": { "t": "نص اقتباس حقيقي", "a": "المصدر" },
      "sum": "خليطة من جملتين تلخّص الفصل وبيّن نتيجته."
    }
  ]
}
```

## المقادير الإلزامية لكل فصل

| الحقل | الحد الأدنى | الحد الأعلى |
|---|---|---|
| عدد فقرات `p` | ٣ فقرات (المستهدف ٧) | ٧ فقرات |
| طول كل فقرة في `p` | ٣٣٠ حرف | ١٢٠٠ حرف |
| `h2` | قسمان (المستهدف ٣) | ٤ أقسام |
| طول فقرة داخل `h2` | ٢٥٠ حرف | ٦٠٠ حرف |
| `key` | ٣ بطاقات (المستهدف ٤) | ٥ بطاقات |
| `tbl` | ٣ صفوف (المستهدف ٥) | ٦ صفوف |
| `sum` | جملتان | — |

**حجم الفصل المستهدف: من ٦٠٠٠ إلى ٩٠٠٠ حرف في JSON.**
**حجم الجزء المستهدف: من ١٠٠ إلى ١٥٠ ألف بايت.**

## القواعد الصارمة

1. **عربية خالصة ١٠٠٪** في كل حقل نصي:
   - لا حرف لاتيني إطلاقًا (الأسماء اللاتينية ممنوعة، ولا حتى في الجداول والاقتباسات).
   - **الأرقام بالحروف العربية ٠١٢٣٤٥٦٧٨٩** — الرقم `0-9` مرفوض من الفاحص. اكتب: ١٢٤٦هـ / ١٨٣٠م.
   - لا حرف صيني أو ياباني أو كوري، ولا محرف تالف `�`.
   - اللاتيني مسموح في الحقلين `id` و`partId` فقط.
2. **وقائع صحيحة ومحددة**: أسماء وأحداث وتواريخ وأعداد. إن لم تتحقق من رقم، اكتب الوصف بدل الرقم المختلق.
3. **لا حشو ولا تكرار**: كل فقرة تضيف معلومة جديدة لم تقلها فقرة سابقة.
4. **ارجع إلى المصدر الأول**: في الموضوعات القرآنية والحديثة، انسب القصة إلى آيتها أو حديثها، ولا تضيف رواية غير مأثورة ولا رأيًا ولا تأويلًا.
5. **عربية فصيحة سلسة**، لا لغة تقارير جامعية جافة.

## مسار العمل

```
1. اكتب الملف في  data/era/<اسم-الحقبة>/NN-<partId>.json
2. نفّذ الفحص     node tools/checkera.js <اسم-الحقبة>
3. أصلح بـ edit دقيق وأعد الفحص حتى يطبع ✔ لا توجد مشاكل
4. أعد البناء     node tools/era.js <اسم-الحقبة>   ثم   node tools/site.js
5. الفحص النهائي  node tools/finalcheck.js
```

> إن كنت تكتب في `data/deep/` (نظام المماليك القديم) فاستعمل `node tools/checkdeep.js <اسم-الملف>`.

**لا تتوقف قبل أن يطبع الفاحص `✔ لا توجد مشاكل`.**
