1. [إصلاح حرج] حماية مشروع أندرويد وتعديل سكريبت البناء: tools/build-app.sh
--------------------------------------------------------------------------------
المشكلة: السكريبت الحالي يحتوي على (rm -rf mobile) مما يمسح إعدادات التطبيق والأيقونات.
الحل: استبدال محتوى ملف tools/build-app.sh بالكود الآمن التالي الذي ينسخ التعديلات زمنيًا:

--- كود tools/build-app.sh المحدث ---
#!/usr/bin/env bash
set -e

ROOT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
cd "$ROOT_DIR"

echo "==> 1. بناء الموقع وتوليد الصفحات..."
node tools/site.js

echo "==> 2. مزامنة الملفات إلى مجلد mobile/app/www/..."
mkdir -p mobile/app/www/assets

# نسخ الصفحات والرموز الرئيسية
cp -u *.html mobile/app/www/ 2>/dev/null || true
cp -u favicon*.png favicon.ico apple-touch-icon_180.png mobile/app/www/ 2>/dev/null || true
cp -ru assets/* mobile/app/www/assets/

echo "==> 3. بناء تطبيق أندرويد عبر Cordova..."
cd mobile/app
npx cordova build android --debug

echo "=========================================="
echo "✔ تم بناء التطبيق بنجاح!"
echo "APK Output: mobile/app/platforms/android/app/build/outputs/apk/debug/app-debug.apk"
echo "=========================================="

3. [إصلاح عالٍ] حل أخطاء FileNotFoundException للأيقونات في أندرويد (Logcat Exception)
--------------------------------------------------------------------------------
المشكلة: رمي استثناءات في WebView بسبب عدم وجود ملفات favicon في جذر mobile/app/www/
الحل: إضافة كود تلقائي في نهاية ملف tools/site.js يضمن نسخ أيقونات الفافيكون لمجلد www:

--- الكود المضاف في نهاية tools/site.js ---
// ضمان نسخ أيقونات الفافيكون إلى مجلد التطبيق لتفادي أخطاء WebView
const favFiles = ['favicon.ico', 'favicon_32.png', 'favicon_64.png', 'apple-touch-icon_180.png'];
const wwwDir = path.join(root, 'mobile', 'app', 'www');
if (fs.existsSync(wwwDir)) {
  favFiles.forEach(f => {
    const srcFile = path.join(root, f);
    if (fs.existsSync(srcFile)) {
      fs.copyFileSync(srcFile, path.join(wwwDir, f));
    }
  });
  console.log('✔ تم نسخ أيقونات الفافيكون إلى mobile/app/www/');
}

6. [إصلاح متوسط] توحيد تحويل الأرقام الهندية العربية في tools/site.js
--------------------------------------------------------------------------------
المشكلة: ظهور الأرقام اللاتينية (ASCII Digits) في التواريخ والفقرات.
الحل: في tools/site.js، تأكد من تحويل حقول التواريخ والأرقام باستخدام دالة ar() بدلاً من esc().

مثال في buildDeep(p):
- بدل: `<span class="cho-cnt">الفصل ${ci + 1} من ${x.chapters.length}</span>`
- استخدم: `<span class="cho-cnt">الفصل ${AR_DIG(ci + 1)} من ${AR_DIG(x.chapters.length)}</span>`
